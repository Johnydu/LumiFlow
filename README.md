# LumiFlow

Sistema de gestão e controle da produção desenvolvido para uma empresa parceira através do Projeto Integrador Extensionista.

## Tecnologias

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- Bootstrap 5
- MySQL
- Flyway
- Maven

## Funcionalidades

- Controle de usuários
- Controle de setores
- Controle de máquinas
- Cadastro de produtos
- Ordens de produção
- Controle de refugo
- Controle de retrabalho
- Dashboard gerencial
